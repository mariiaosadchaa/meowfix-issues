# 🚀 Issue Tracker & Feature Requests

Ласкаво просимо! Цей репозиторій призначений **виключно для збору повідомлень про помилки (Bug Reports) та пропозицій щодо нового функціоналу (Feature Requests)** для нашого проекту.

Сам вихідний код проекту є закритим, але ми відкриті до вашого фідбеку та допомоги у покращенні продукту.

---

## 📌 Як повідомити про проблему або запропонувати ідею?

Щоб створити новий запит:

1. Перейдіть у вкладку [**Issues**](../../issues).
2. Натисніть кнопку **New issue**.
3. Оберіть відповідний шаблон:
   * 🐛 **Bug Report** — якщо ви знайшли помилку чи баг у роботі системи.
   * 💡 **Feature Request** — якщо у вас є ідея щодо нового функціоналу чи покращення.
4. Заповніть усі обов'язкові поля форми та натисніть **Submit new issue**.

> ⚠️ **Зверніть увагу:** Створювати Issues можуть тільки зареєстровані користувачі GitHub.

---

## 🔍 Перед тим, як створити Issue

* **Перевірте існуючі запити:** Скористайтеся пошуком у вкладці [Issues](../../issues), щоб переконатися, що про вашу проблему або ідею ще не повідомляли.
* **Надавайте деталі:** Чим детальніше ви опишете кроки для відтворення або вашу ідею (із додаванням скріншотів), тим швидше ми зможемо взяти це в роботу.
